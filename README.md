# Веб-аналитика: лабораторные 1–5

Учебный статический сайт по материалам Московского Политеха.

Сайт: https://dimazikskyter.github.io/web-analytics-labs/

Работы 1–2 содержат теоретические отчёты. Работы 3–5 содержат теорию, ответы и протоколы практики. 07.10.2026 подключены LiveInternet (код владельца), Sber Ads 7752692 и MyTracker 3800180 (приложение 1084943) на всех шести страницах. В Sber Ads подтверждены просмотры и по одному тестовому достижению целей `printReport` и `openSource`; сохранены две конверсии и два собственных отчёта. В MyTracker сохранены два шаблона, но поступление данных пока не подтверждено. LiveInternet при проверке в браузере вернул `ERR_CONNECTION_CLOSED`. Для завершения работ 3–5 требуется 1–2 недели наблюдения и минимум 50 реальных пользователей.

## Сборка

Python 3, без внешних зависимостей:

```powershell
python build.py
python build.py --output docs
python -m http.server 8765 --bind 127.0.0.1 --directory site
```

`content/` — исходники отчётов, `status.json` — статусы, `site/` — локальная сборка. `integrations/` содержит официальный публичный код, `counters.json` — ID, `assets/counters.js` — обработчики целей. На GitHub опубликованная сборка находится в `docs/`; Pages настроен на ветку `main`, каталог `/docs`.

## Продолжение практики

1. Подтвердить поступление просмотров и `printReport` / `openSource` в MyTracker. Проверка Integration status на 07.10.2026, 23:29 МСК показывала No data; кабинет предупреждает о задержке до двух часов.
2. Проверить доступность `counter.yadro.ru` и появление данных в LiveInternet. Ошибка в одном браузере не доказывает общую недоступность сервиса.
3. После 7–14 полных суток и ≥50 реальных пользователей установить одинаковый фиксированный период в отчётах, добавить агрегированные выгрузки, скриншоты, портрет аудитории и выводы. Тестовые посещения учитывать отдельно, дневные уникальные не суммировать. Личные данные посетителей не публикуются.

Сохранены конверсии Sber Ads 27713/27714 и отчёты «Источники и полезные действия», «Отчёты и устройства». Шаблоны MyTracker 24622/24623: «Источник → полезное действие», «Страница × устройство», фильтр приложения 1084943, период 14 дней, часовой пояс Москва. Для блоков Sber Ads используется `data-analytics-block`; официальный виджет размещён в подвале.

Исходные сохранённые HTML СДО, изображения лекций и исследовательские файлы не входят в публичную публикацию: они содержат чужие учебные материалы и служебную разметку аккаунта. Сайт содержит собственные отчёты со ссылками на источники.
