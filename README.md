# Веб-аналитика: лабораторные 1–5

Учебный статический сайт по материалам Московского Политеха.

Сайт: https://dimazikskyter.github.io/web-analytics-labs/

Работы 1–2 содержат теоретические отчёты. Работы 3–5 содержат теорию, ответы и протоколы практики; собственные счётчики ещё не зарегистрированы. Измерения не выдуманы. Для завершения по заданиям требуется 1–2 недели наблюдения и минимум 50 пользователей.

## Сборка

Python 3, без внешних зависимостей:

```powershell
python build.py
python build.py --output docs
python -m http.server 8765 --bind 127.0.0.1 --directory site
```

`content/` — исходники отчётов, `status.json` — статусы, `site/` — локальная сборка. На GitHub опубликованная сборка находится в `docs/`; Pages настроен на ветку `main`, каталог `/docs`.

## Продолжение практики

1. Владелец входит/регистрируется в LiveInternet, SberAds и MyTracker.
2. Создаёт счётчики для полного адреса проекта; сохраняются только публичные ID и официальный код. Пароли и токены в репозиторий не помещаются.
3. В общий шаблон добавляется выданный код один раз, официальные значки — внизу страниц; проверяется поступление данных.
4. В SberAds и MyTracker настраиваются `printReport` и `openSource`, конверсии/отчёты по схемам на страницах.
5. После 7–14 суток и ≥50 реальных пользователей добавляются агрегированные выгрузки, скриншоты, портрет аудитории и выводы. Личные данные посетителей не публикуются.

Исходные сохранённые HTML СДО, изображения лекций и исследовательские файлы не входят в публичную публикацию: они содержат чужие учебные материалы и служебную разметку аккаунта. Сайт содержит собственные отчёты со ссылками на источники.
