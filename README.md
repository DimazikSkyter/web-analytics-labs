# Веб-аналитика: лабораторные 1–5

Учебный статический сайт по материалам Московского Политеха.

Сайт: https://dimazikskyter.github.io/web-analytics-labs/

Работы 1–2 содержат теоретические отчёты. Работы 3–5 содержат теорию, ответы и протоколы практики. 07.10.2026 подключены LiveInternet (код владельца), Sber Ads 7752692 и MyTracker 3800180 (приложение 1084943). Обработка просмотров и целей проверяется в кабинетах. Для завершения по заданиям требуется 1–2 недели наблюдения и минимум 50 реальных пользователей.

## Сборка

Python 3, без внешних зависимостей:

```powershell
python build.py
python build.py --output docs
python -m http.server 8765 --bind 127.0.0.1 --directory site
```

`content/` — исходники отчётов, `status.json` — статусы, `site/` — локальная сборка. `integrations/` содержит официальный публичный код, `counters.json` — ID, `assets/counters.js` — обработчики целей. На GitHub опубликованная сборка находится в `docs/`; Pages настроен на ветку `main`, каталог `/docs`.

## Продолжение практики

1. Подтвердить поступление просмотров и `printReport` / `openSource` в кабинетах. Тестовые посещения фиксируются отдельно.
2. Сохранить конверсии и отчёты по схемам на страницах. Для блоков Sber Ads используется `data-analytics-block`, официальный виджет размещён в подвале.
3. После 7–14 суток и ≥50 реальных пользователей добавить агрегированные выгрузки, скриншоты, портрет аудитории и выводы. Дневные уникальные не суммировать. Личные данные посетителей не публикуются.

Исходные сохранённые HTML СДО, изображения лекций и исследовательские файлы не входят в публичную публикацию: они содержат чужие учебные материалы и служебную разметку аккаунта. Сайт содержит собственные отчёты со ссылками на источники.
