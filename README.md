# СмартВыбор

Статический сайт о выборе смартфонов. Главная страница предлагает поиск по моделям и задачам, пять отдельных материалов разбирают iPhone 17, Samsung Galaxy S25, Redmi Note 14 Pro 5G, POCO X7 Pro и Google Pixel 9a.

Сайт: https://dimazikskyter.github.io/web-analytics-labs/

## Сборка

Python 3.12, без внешних зависимостей:

```powershell
python build.py
python build.py --output docs
```

Содержимое моделей и FAQ хранится в models.json, статьи — в content/. Шаблон и метаданные формируются build.py. В сборку копируются только четыре файла интерфейса из assets/. Опубликованная сборка находится в docs/, GitHub Pages использует main и /docs.

Страницы: index.html, iphone-17.html, samsung-galaxy-s25.html, redmi-note-14-pro-5g.html, poco-x7-pro.html, google-pixel-9a.html. Старые адреса перенаправляют на новые материалы; в sitemap включены только шесть основных страниц.

## Данные

Характеристики сверены 08.10.2026 по официальным страницам Apple, Samsung, Xiaomi и Google; ссылки приведены в статьях. Для Redmi и POCO используются глобальные версии. Цены и наличие не фиксируются. Советы по выбору представляют интерпретацию параметров, без заявлений о собственных испытаниях устройств.

## Аналитика

На шести основных страницах подключены официальный код LiveInternet, Sber Ads 7752692 и MyTracker 3800180. IDs и адаптеры сохранены. Реальные клики печати/PDF передают printReport, переходы к спецификации производителя — openSource. Поиск работает локально и не создаёт искусственных посещений.

Локальные исследовательские файлы и прежние материалы остаются в research/ и не публикуются.
